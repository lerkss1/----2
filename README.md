Описание заданий
В папке Lab_2 находятся решения следующих задач:
Задания A4-A7 (Базовый уровень):
task_A4.py — нахождение наибольшего из двух чисел (без использования ветвлений).
task_A5.py — проверка кратности числа A числу B.
task_A6.py — перевод количества секунд в формат электронных часов (ЧЧ:ММ:СС).
task_A7.py — определение цвета шахматной клетки и проверка, находятся ли две клетки на одном цвете.
Задание B1 (Продвинутый уровень):
task_B1.py — вычисление реального расстояния между локациями по карте. Программа считывает данные из файла inmap0.dat (количество локаций и масштаб) и выводит красивый отчет.

Инструкция по запуску
Убедитесь, что у вас установлен Python 3.
Скачайте папку Lab_2 целиком (или склонируйте весь репозиторий).
Для запуска любой программы откройте терминал (командную строку) в папке Lab_2 и введите:
python task_A4.py
